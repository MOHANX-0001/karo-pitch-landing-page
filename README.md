# Karo Pitch Landing Page

This project is a demo landing page created as part of the KaroStartup internship assignment.

The goal was to design a modern startup-style homepage that explains the Karo Pitch platform and encourages founders to apply.

## Features

- Modern hero section
- Smooth scrolling navigation
- Startup landing page layout
- Hover UI animations
- Scroll reveal animations
- Responsive grid layout

## Technologies Used

- HTML
- CSS
- JavaScript

## About Karo Pitch

Karo Pitch is a platform where founders across India can pitch their startups directly to investors and raise funding.

## Demo

This project demonstrates a clean and modern UI suitable for startup ecosystems.
